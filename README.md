## Terminal Compatibility

**Windows Terminal** is recommended, as the legacy Command Prompt (conhost.exe) on Windows 10 can cause visual glitches. Windows 11's default terminal and most Linux/macOS terminals work fine without changes.

To install **Windows Terminal**: search "Windows Terminal" in the Microsoft Store.
